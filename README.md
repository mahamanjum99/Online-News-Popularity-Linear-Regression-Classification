# 📰 Online News Popularity Analysis

## 📌 Project Overview

This project focuses on analyzing and predicting the popularity of online news articles using Machine Learning and Statistical techniques. 

The notebook includes complete data preprocessing, exploratory data analysis, visualization, linear regression, and classification techniques to study how different features affect the popularity of online news articles.

# 📂 Dataset

The project uses the **Online News Popularity Dataset**, which contains various features related to online news articles such as:

* Number of words in the title
* Number of images and videos
* Article category
* Keyword statistics
* Social media shares
* Publishing information

The dataset is used to predict and analyze article popularity.
